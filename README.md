## 功能说明

- **四册总导航**：`index.html`（A1–C2 总览，含各册入口）
- **每册首页**：`libroN/index.html`（单元导航卡）
- **词汇 · 句型**：`libroN/vocabolario.html`（按单元 / 类别 / 首字母 / 类型筛选，支持搜索与发音，可隐藏中文自测）
- **自动生成练习**：`libroN/esercizi.html`（选择题 · 填空 · 意中互译，即时判定并记录正确率，数据保存在浏览器本地）
- **真人发音**：全部意大利语单词 / 例句 / 对话点击朗读，音频由 `edge-tts` 生成，可离线使用
